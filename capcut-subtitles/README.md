# CapCut용 고정확도 자막 만들기

영상 파일을 끌어다 놓으면 **Whisper large-v3**(가장 정확한 Whisper 모델)로 받아써서
CapCut에서 불러올 수 있는 **SRT 자막 파일**을 만들어 줍니다.

- 무료이고, 영상이 인터넷에 올라가지 않아요 (내 PC 안에서만 처리)
- 단어 하나하나의 타이밍을 맞춰서 자막 싱크가 정확해요
- 자주 틀리는 이름/용어는 단어장에 적어 두면 더 잘 알아듣고, 자동으로 고쳐줘요

## 준비물

- Windows 10 또는 11 PC
- 인터넷 (설치할 때만)
- 디스크 여유 공간 약 6GB
- NVIDIA 그래픽카드가 있으면 훨씬 빨라요 (없어도 CPU로 동작, 정확도는 거의 같아요)

## 1. 설치 (처음 한 번만)

1. 이 폴더(`capcut-subtitles`)를 PC에 내려받아 압축을 풉니다.
   - 압축 풀기 전에 zip 파일을 **오른쪽 클릭 → 속성 → "차단 해제" 체크 → 확인** 하면 경고창이 덜 떠요.
2. `1-setup.bat` 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
3. 10~30분 정도 기다리면 `설치 완료!` 가 나옵니다.

설치되는 것(파이썬, 음성 인식 프로그램, 인식 모델)은 모두 **이 폴더 안에만** 들어갑니다.
지우고 싶으면 폴더를 통째로 삭제하면 끝이에요.

## 2. 자막 만들기

- 영상 파일을 `2-make-subtitles.bat` **위에 끌어다 놓으세요.** (여러 개를 한 번에 놓아도 돼요)
- 또는 `2-make-subtitles.bat` 을 더블클릭하면 파일 고르는 창이 열려요.

영상과 같은 폴더에 같은 이름의 `.srt` 파일이 생깁니다.
(예: `브이로그.mp4` → `브이로그.srt`, 이미 있으면 `브이로그 (2).srt`)

걸리는 시간 (대략):
- CPU만: 영상 길이의 절반~비슷한 정도 (4코어 CPU에서 2분짜리 영상이 약 1분)
- NVIDIA 그래픽카드: 그보다 몇 배 빠름

## 3. CapCut(PC)에서 불러오기

1. CapCut에서 영상을 타임라인에 올립니다.
2. 위쪽 **텍스트** 탭 → 왼쪽 **로컬 자막** → **가져오기** 를 누르고 `.srt` 파일을 고릅니다.
   (메뉴 이름은 CapCut 버전에 따라 조금 다를 수 있어요)
3. 불러온 자막은 CapCut 안에서 글꼴, 색, 위치를 한 번에 바꾸고 틀린 글자도 고칠 수 있어요.

## 정확도를 더 높이는 방법

**단어장 (`words.txt`)** — 메모장으로 열어서 아래에 적고 저장하세요.

```
캡컷
클로드
갭컷 -> 캡컷
```

- 그냥 적은 단어: 인식할 때 힌트로 사용 (사람 이름, 브랜드, 전문용어)
- `틀린말 -> 맞는말`: 자막에서 자동으로 바꿔줌

**설정 (`config.txt`)** — 메모장으로 열어서 값만 바꾸세요.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `max_chars` | 20 | 자막 한 줄 최대 글자 수. 세로 쇼츠 14~20, 가로 영상 25~35 추천 |
| `max_seconds` | 6 | 자막 하나가 떠 있는 최대 시간(초) |
| `remove_period` | yes | 문장 끝 마침표·쉼표 지우기 |
| `language` | ko | 언어 (en, ja, auto 등) |
| `model` | large-v3 | 가장 정확함. 너무 느리면 `large-v3-turbo` |
| `device` | auto | GPU 있으면 GPU 사용 |

**소리가 깨끗할수록 정확해요.** 배경음악이 크게 깔린 영상이라면, 음악을 넣기 전 원본 영상(목소리만 있는 것)으로 자막을 만드세요.

## 문제가 생기면

- **GPU가 있는데 "CPU로 실행합니다"라고 나와요** → NVIDIA 그래픽 드라이버를 최신으로 업데이트한 뒤 `1-setup.bat` 을 다시 실행하세요.
- **설치 중 실패** → 인터넷 연결과 디스크 공간을 확인하고 `1-setup.bat` 을 다시 실행하세요. 이미 받은 것은 건너뜁니다.
- **"uv trampoline failed to spawn Python" 오류가 나요** → 설치한 뒤 폴더를 옮기거나 이름을 바꾸면 생겨요. 폴더 안의 `.venv` 폴더만 지우고 `1-setup.bat` 을 실행하세요. 모델은 다시 받지 않아요. (최신 버전은 `2-make-subtitles.bat` 이 알아서 다시 만들어요)
- **처음부터 다시 설치하고 싶어요** → 이 폴더 안의 `.venv`, `tools`, `models` 폴더를 지우고 `1-setup.bat` 을 실행하세요.

## Claude에게 보여줄 샘플 만들기

자막이 이상해서 파일을 보여줘야 하는데 용량이 크면, 오디오 파일을 `3-make-sample.bat` 위에 끌어다 놓으세요.
앞 3분만 작은 MP3(약 1MB, `이름_sample.mp3`)로 만들어 줍니다. 음성 인식은 원래 이 품질로 처리하므로 결과는 같아요.

## 테스트 결과

정답 문장이 있는 한국어 음성(화자 8명, 12문장, 약 2분)으로 시험한 결과입니다. (4코어 CPU, 약 1분 걸림)

- **글자 오류율 약 2.4%** (451자 중 11자). 이 중 상당수는 "백 명 → 100명", "두 살 → 2살" 같은
  숫자 표기 차이나 띄어쓰기 차이이고, 실제로 잘못 들은 단어는 "출격 → 출력", "주선 → 조선" 같은 몇 개였어요.
- **싱크**: 자막은 말소리보다 0.1~0.4초 먼저 나타나고, 말이 끝난 뒤 0.2초 이내에 사라져요.
- 자막 한 줄은 설정한 20자를 넘지 않았어요.
